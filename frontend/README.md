# English Center frontend

Chạy `npm ci`, sau đó `npm run dev` trong thư mục frontend. Mở địa chỉ Vite in trong terminal. Khi tích hợp thật, Spring Boot cần chạy trên cổng 8080 để proxy chuyển các yêu cầu /api. Với bản build, máy chủ phục vụ frontend cần chuyển /api về Spring Boot trên cùng origin.

Học viên chọn khóa học, học phần và lớp, sau đó xem hóa đơn vừa nhận hoặc tra cứu bằng mã. Kế toán nhập mã hóa đơn và mã tham chiếu của khoản thu. Khi gửi lại cùng khoản thu, giữ nguyên mã tham chiếu.

`npm test` chạy kiểm tra giao tiếp API với fetch giả lập. `npm run build` kiểm tra bản build frontend.
